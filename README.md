# Авиагородок — локально-исторический сайт

Редакционный digital-проект о микрорайоне Авиационный (Авиагородок) в составе
городского округа Домодедово, выросшем вместе с аэропортом Домодедово.

Сайт рассказывает:
— как возник микрорайон;
— как он связан со строительством аэропорта;
— чем образован его каркас (станция, ДК «Авиатор», стела, парк «Взлёт», храм);
— как сюда добраться и что логично посмотреть;
— на какие источники опирается проект.

## Стек

— **Next.js 16** (App Router) + React 19
— **TypeScript** (strict)
— **Tailwind CSS 3**
— Статический экспорт целиком из SSG (все маршруты `○ Static`)
— Собственные SVG-иллюстрации и схематическая карта (без сторонних медиа)

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
```

## Сборка

```bash
npm run build
npm run start
```

Все страницы рендерятся как статические (SSG) — сайт подходит для любого
статического хостинга.

## Деплой

### Vercel

```bash
npx vercel            # первый раз — привязка
npx vercel --prod
```

### Любой статический хостинг

Next.js 16 App Router поддерживает полноценный статический экспорт. Для
хостинга как статики:

1. Раскомментируйте / добавьте в `next.config.mjs`:
   ```js
   const nextConfig = { output: "export" };
   ```
2. Соберите:
   ```bash
   npm run build
   ```
3. Выгрузите содержимое `out/` на Netlify, GitHub Pages, Cloudflare Pages и т.д.

## Контент и источники

Сайт использует иерархию доверия в таком порядке:

1. Официальный сайт городского округа Домодедово
2. Официальные материалы аэропорта Домодедово
3. Официальные материалы ДК «Авиатор»
4. Wikimedia Commons и лицензируемые медиа
5. Стабильные справочные источники (транспорт, топонимика)
6. Локальные публикации — как вторичный контекст

Где официальный и локальный источник расходятся (например, год первых домов —
1962 или 1963), сайт не выбирает одну версию, а показывает обе.

## Изображения и права

На сайте **не используются** архивные фотографии со спорным лицензионным
статусом. Все иллюстрации — собственные SVG, помеченные как иллюстрации.
Полная атрибуция — на странице `/sources`.

## Что сознательно не делается

— Нет тёмной темы.
— Нет выдуманных цифр населения, рейтингов и «уникальностей».
— Нет советов, связанных с нарушением режима аэропорта и несанкционированным споттингом.
— Нет подмены иллюстраций под «архивные фото».
